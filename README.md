# Flora — «Цифровой улей»

Локальное настольное приложение на **JavaFX** для анализа показаний датчиков улья, оценки погодных условий для лёта пчёл и поддержки решений пчеловода. Приложение работает полностью офлайн и не требует облачных ключей.

---

## Основные возможности

- **Интерактивный дашборд улья** — выбор пасеки, улья и периода отображения (`Сутки`, `3 дня`, `Неделя`, `Месяц`), карточки текущих значений со спарклайнами и графики динамики массы и внутренней температуры.
- **Загрузка таблиц CSV** — встроенная демонстрационная таблица эксперта при старте и возможность загрузить собственный CSV-файл датчиков (`;`, `,`, русские и английские заголовки, 7 форматов даты/времени). Пропущенные значения не подменяются нулями.
- **Два раздельных аналитических контура**:
  - **`Health_Index` (условный «индекс счастья / здоровья пчёл», шкала `0,5–5,0`)** — локальный расчёт через встроенную нейросеть в формате **ONNX Runtime** по 15 признакам записи улья. Подаётся как ориентир для наблюдения, а не ветеринарный диагноз.
  - **Погодный индекс (шкала `0,00–5,00`)** — отдельный расчёт благоприятности погоды для вылета пчёл и медосбора по дневным метеоданным и экспертной формуле (температура, влажность, облачность/осадки, скорость и направление ветра).
- **Диалоговый помощник Flora и Hot Words** — быстрые кнопки-подсказки в один клик с объяснением показателей выбранного улья за активный период:
  - `Вес улья`, `Температура в улье`, `Влажность`, `CO₂`, `Температура снаружи`, `Ветер и дождь`, `Погодный индекс`, `Индекс счастья` (подробная памятка — в [`docs/Flora_Hot_Words.docx`](docs/Flora_Hot_Words.docx)).
- **Защита от некорректных выводов** — при нехватке входных измерений или выходе даты за подтверждённый диапазон числовой индекс не выдумывается, а интерфейс объясняет причину ограничения.

## Технологический стек

- **Java 17+**
- **JavaFX 21.0.5** (`javafx-controls`)
- **Microsoft ONNX Runtime 1.22.0** (локальный инференс модели)
- **Apache Maven** + `jpackage` (сборка переносимого Windows-приложения)

---

## Быстрый запуск из исходников

Требуются установленные **JDK 17+** и **Apache Maven** в `PATH`.

### Windows (в один клик или через консоль)
```bat
run-flora.bat
```
или напрямую через Maven:
```powershell
mvn clean javafx:run
```

---

## Сборка автономного Windows EXE (`Flora.exe`)

В PowerShell из корня проекта выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\build-windows.ps1
```

Готовый переносимый пакет со встроенным Java runtime создаётся в:
- `dist\Flora\Flora.exe` (папку `Flora` нужно переносить целиком вместе с соседними каталогами `app` и `runtime`);
- `dist\Flora-portable-Windows.zip`.

*(Готовый архив для Windows рекомендуется прикладывать во вкладку **Releases** репозитория GitHub, а не коммитить папку `dist/` в ветку исходного кода).*

## Структура репозитория

```text
├── pom.xml                        # Конфигурация сборки Maven
├── run-flora.bat                  # Быстрый запуск приложения через Maven
├── scripts/
│   └── build-windows.ps1          # Сборка portable Windows EXE через jpackage
├── docs/
│   └── Flora_Hot_Words.docx       # Памятка по показателям и кнопкам Hot Words
└── src/main/
    ├── java/ru/digitalhive/
    │   ├── ui/                    # Интерфейс JavaFX (окно, дашборд, графики, чат Flora)
    │   ├── agent/                 # Локальный ИИ-агент, ONNX-модель и справочник Hot Words
    │   ├── weather/               # Загрузка погоды и расчёт погодного индекса
    │   ├── data/                  # Чтение и валидация CSV-таблиц
    │   └── model/                 # Предметные модели, периоды и агрегация рядов
    └── resources/
        ├── css/styles.css         # Тёмная тема оформления
        ├── images/apiary-mark.png # Логотип помощника Flora
        ├── data/                  # Встроенные демонстрационные CSV-таблицы
        └── models/                # Локальная ONNX-модель и параметры проверки диапазонов
```
